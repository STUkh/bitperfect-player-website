# Фоны секций

Четыре композиции: дневной свет, ореховый отсвет, боковой свет и диагональная тень. Каждая имеет тёмную и светлую версию. [Сравнить варианты](http://localhost:4321/preview/background-flow) можно через `npm run dev`.

## Правила

- Спокойные нейтральные и древесные полутона; без золочёных узоров, сеток, точек и предметов.
- Свет доходит до боковых краёв. Верх и низ плавно уходят в прозрачность, чтобы стыковаться с основой секции.
- Один фон может объединять несколько секций. Контент сохраняет обычные отступы.
- Между разными цветами основы прозрачность не создаёт переход: при необходимости используйте отдельный `soft-bridge` между блоками.
- Фон статичный: без runtime blur, анимации и принудительного GPU-слоя.

## Выбор и подключение

На главной странице фоны выбираются через `chooseFlowSequence('home', ['statement', 'features', 'privacy', 'pricing', 'cta'])` в [`index.astro`](../src/pages/index.astro). Варианты псевдослучайны, воспроизводимы по ключу страницы и секции и **не повторяются на соседних блоках**. Перезагрузка и смена темы не меняют композицию. Для другой последовательности измените ключ страницы; при добавлении блока включите его в общий список ключей.

Компоненты секций принимают `backgroundVariant`. Общий `Band` и `CloseBand` передают его в [`FlowBackdrop`](../src/components/bands/FlowBackdrop.tsx); секции с собственной разметкой используют этот компонент напрямую. На светлой основе передавайте `light`. Новое поле заменяет старый декоративный фон, а не накладывается поверх него.

Для Astro и общих контейнеров остаётся `SoftBackdrop family="flow" variant="walnut" theme="light"` внутри `soft-surface` с `data-soft-theme="light"`.

## Ассеты

- Восемь прозрачных WebP 128×128: `public/backgrounds/soft/v3/`, **15 420 байт суммарно**. Мягкость уже записана в пикселях; дополнительные размеры не нужны.
- Параметры: [`design/flow-backgrounds.json`](../design/flow-backgrounds.json). Пересборка: `node scripts/flow-backgrounds.mjs`.
- Каталог: [`flowBackgrounds.ts`](../src/data/flowBackgrounds.ts), выбор: [`flow-background.ts`](../src/utils/flow-background.ts).
- [Проверка палитры](../design/flow-backgrounds-audit.json): минимальный контраст основного текста 4,90:1 на тёмном `#1c1b21` и 4,71:1 на белом. При изменении цветов или интенсивности проверяйте контраст заново.
