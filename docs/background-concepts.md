# Концепты спокойных CTA-фонов

20 отдельных изображений сгенерированы встроенным `image_gen`, по одному вызову на вариант. Это поисковая серия для выбора фона; основной сайт пока не переведён на новый вариант.

## Просмотр

Запустите `npm run dev` и откройте [страницу сравнения](http://localhost:4321/preview/backgrounds). Она доступна только в режиме разработки.

- Нажатие на миниатюру показывает фон в полноразмерном CTA с одинаковыми текстом и кнопками.
- Доступны центральная и левая композиции, затемнение 0–70%, фильтр по четырём направлениям и открытие чистого фона.
- Ссылка с номером сохраняет выбор, например `/preview/backgrounds#bg-17`.
- Все миниатюры показываются без затемнения; если оно потребуется для финального применения, значение нужно зафиксировать отдельно.

[Общий лист концептов](references/cta-background-concepts.jpg)

## Файлы

- `public/img/concepts/cta/01.webp` … `20.webp` — чистые фоны, WebP 1920×1080, качество 80.
- `design/background-concepts/01-cta.png` … `20-cta.png` — 20 визуальных концептов с CTA поверх фона, снимки браузера 1440×520.
- `design/generated-backgrounds/01-raw.png` … `20-raw.png` — исходники генерации.
- [`design/generated-backgrounds/manifest.json`](../design/generated-backgrounds/manifest.json) — точный промпт каждого вызова, исходный файл, финальный путь, группа и название.
- `src/data/backgroundConcepts.ts` — каталог для страницы предпросмотра.
- `src/components/preview/BackgroundConcepts.astro` — интерактивное сравнение, использующее настоящий `ClosingBanner`.

## Как выбирать

Сначала оцените читаемость и внимание к кнопке при нулевом затемнении. Затем сравните текстуру и теплоту с фотографиями аудиотехники. Проверьте мобильный кроп: детали у краёв могут исчезнуть, и фон всё равно должен выглядеть цельным.

Мой предварительный короткий список: **06** — мягкий боковой свет; **10** — спокойная диагональ света; **16** — связь с ореховыми корпусами; **17** — мягкая ткань. **11–12** полезны как почти однородные контрольные варианты. Ни один из них ещё не выбран пользователем для основного сайта.

Варианты 01–02 были запрошены как ровные поверхности, но генератор добавил интерьер у края. Они сохранены как самостоятельные интерьерные концепты и перенесены в соответствующую группу; промпты в манифесте отражают фактические вызовы.
