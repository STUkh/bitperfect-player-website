On device

Nothing is looked up anywhere

The index is built on the phone, from the files you already have. Search your whole collection by title, performer or album and it answers instantly, because the question never leaves the phone: no catalogue service, no scraping, no account.

Formats

Fifteen formats, including the ones other players give up on

DSD disc images, Monkey's Audio, WavPack and TAK sit alongside FLAC, ALAC, WAV, AIFF, DSD, True Audio, Musepack, Opus, Vorbis, MP3 and AAC: the awkward formats a real archive still has, not just the easy ones. Tags and embedded artwork are read straight out of the file itself, even when it has been renamed or the extension is wrong.

Playlists

It reads the playlists you already have

Import covers M3U, M3U8, PLS, XSPF, ASX and CUE, and it recognises the format even when a file arrives without a usable extension. A playlist you build here stays here: export is not built yet, and the app says so upfront.
